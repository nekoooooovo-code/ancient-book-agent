# 公网部署步骤（Streamlit Community Cloud）

1. 将整个 `ancient_book_agent` 文件夹上传到一个 GitHub 仓库根目录。
2. 确认仓库中存在 `app.py`、`requirements.txt`、`data/天工开物古籍修复本体.rdf`。
3. 登录 Streamlit Community Cloud，选择 **Create app**。
4. 选择 GitHub 仓库、分支，Main file path 填 `app.py`。
5. 点击 Deploy，等待构建完成即可得到公开 URL。
6. 用手机无登录状态访问 URL 验证。
7. 将 URL 生成二维码，填入比赛作品建设说明书的“测试链接/二维码”。

## 如需启用大模型
在 Streamlit 的 App settings → Secrets 中配置对应环境变量或在部署平台的环境变量设置中配置：

```
LLM_BASE_URL=兼容 Chat Completions 的 API 根地址
LLM_API_KEY=你的 Key
LLM_MODEL=模型名
```

不配置 LLM 时，应用仍可完整演示本体查询、属性链规则、RAG 和 Agent 工具轨迹。
